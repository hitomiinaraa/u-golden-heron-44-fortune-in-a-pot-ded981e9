Entry for the [Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9) bounty on make.fun.

The entry is a single kind, funny fortune for the houseplant on the windowsill, written as a prediction about the plant's own future: it will outgrow its pot, charm its keeper into a bigger one, and never once say thank you. One line, 93 characters.

## Run

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt` and prints it to stdout.
